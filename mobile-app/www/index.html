How offline phone alerts work
  • Tap Allow phone alerts → phone shows notification bar even when app closed (Capacitor LocalNotifications).
  • Every app open, it checks expiry (tomorrow = 1 day left → Orange, past = Red) and fires local notification.
  • Data saved in localStorage on phone — no internet needed. Export via button below.
  • APK: build via npx cap add android && npx cap open android → Android Studio → Build APK.
